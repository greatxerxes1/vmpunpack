# Code of conduct

## The short version

Be decent. Assume the other person is competent and acting in good faith. Criticise the code, the
analysis or the claim — not the person making it.

## Not acceptable

Harassment, personal attacks, or demeaning comments about anyone's background or level of experience.
Publishing anyone's private information. Deliberately derailing discussions.

## Scope and malware specifics

This applies in issues, pull requests and commit messages.

Two rules particular to this project:

- **Do not attach live samples** to issues, PRs or comments. Reference them by SHA-256.
- Do not ask for, or offer, help with making malware harder to analyse. This project exists for the
  other direction.

## Enforcement

Report a problem privately to the maintainer through
[GitHub's report form](https://github.com/contact/report-abuse) or a private security advisory.
Reports are handled confidentially. Maintainers may edit, hide or delete contributions that break these
rules, and may block repeat offenders.
